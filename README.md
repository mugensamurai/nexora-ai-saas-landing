# NEXORA — Portfolio Landing Page

A polished, responsive AI SaaS landing page created as a front-end portfolio case.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Open locally
Double-click `index.html` or open the folder in VS Code and use Live Server.

## Notes
- No build step is required.
- The page uses Google Fonts when online; otherwise it falls back to system fonts.
- This is a fictional portfolio concept, not a real SaaS product.
